Салыстырмалы атомдық массалар

H 1C 12N 14O 16F 19Na 23S 32

Формулалар

n = m / M  ·  n = V / 22,4 (газ, қ.ж.)
ω = m(зат) / m(ерітінді)
C = n / V(ерітінді, л)
ω(элемент) = n · Ar / Mr
M = 2 · D(H2)
x : y : z = ω(C)/12 : ω(H)/1 : ω(O)/16
Вант-Гофф: v2 = v1 · γ(t₂ − t₁)/10
Жылдамдық неше есе артса, реакция уақыты сонша есе қысқарады.
